## Cancellation, Failure and Resource Custody

Ordinary updateSource (including equal bytes), draft/switch/dispose/handover,
cancelAll and retirement withdraw native continuation and cancel original cohort
leases. A direct original lease cancellation closes SDK permission before its
abort/finalization callbacks; unfinished native/peer cleanup stays in the same
private holder for explicit retry. cancelAttachmentRevisionCohort accepts the
original SDK token or an exact original member lease when acquisition threw
before the token escaped. It invokes native cancellation and every original
running task cancellation independently. False/throw, still-running tasks and
caught cleanup reentry retain that holder; success alone removes it. First/latest
raw causes, including undefined, remain inspectable after successful cleanup.

inspectAttachmentRevisionCohortCleanup reports retained cohort holders, not a
complete numeric resource census. Original adapter pendingTaskRefs still owns
unsettled tasks. Historical completed envelopes stay completed when subsequent
withdrawal fails. No token, publication, native cancel result or empty holder
count is an SDK/native/network/Wasm settlement, zero-resource or ready receipt.
Successful withdrawal releases cohort member/event references; weak historical
failure carriers contain only original raw causes, not copied body/history.
