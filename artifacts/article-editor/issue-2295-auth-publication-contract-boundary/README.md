Decision: Main final callback-free guard proves continuity of the SAME original
producer-observed local principal/permissions/session/private-surface projection.
It does not authorize a server operation or attest unknown remote revocation/
precise wall-clock expiry during a blocked JS task. No reviewed original clause
requires those remote atomic guarantees for local retained pointer publication.

The guarantee is bounded to observed local facts through that synchronous operation.
An unknown remote revoke is not a local event; a callback-free token does not read
server time or advance a JS event queue. Local token possession is not server auth.
Server reads/writes keep their original authenticated endpoints and authorization;
401/forbidden/expired observations must close local admission. Reconnect/restore
requires original current permission/query provenance, never client-side filtering.

Current real backend validates revoke/idle/absolute expiry in AdminSessionProjection
using server TimeProvider; AdminSessionValidationService returns only IsValid/Reason,
keeping lifetimes internal to touch scheduling. admin/me DTO/frontend snapshot does
not carry projection lifetimes/version. JWT OnTokenValidated invokes that original
validation. Frontend adminCheckedAt+refresh TTL describes refresh cadence, not a
server lifetime. No self-issued deadline, JWT/cache TTL substitution or backend
write is added. Even adding a DTO deadline would not make remote revocation atomic
with browser-local memory publication.

If a later explicit contract demands remote linearizable authorization, it needs
an original server session/permission version or scoped lease and server operation
validation/publication protocol; a deadline alone is insufficient. That protocol
is absent and such a guarantee must remain unavailable. No such extra goal/ticket
or frozen requirement is invented for #2294/#2295 in this handoff.
