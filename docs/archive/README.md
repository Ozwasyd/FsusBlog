# 历史文档归档（只读）

> **角色**：历史归档（只读）
> **适用对象**：追溯 v1 基线与早期研发决策的维护者
> **权威依据**：本目录不代表当前 FsusBlog v2 的现行规范、支持范围或发布状态；请以 [文档总索引](../index.md) 中的现行文档为准。

## 目录内容

- [`v1-baseline/`](v1-baseline/)：FsusBlog v1 静态参考基线、P0 开放议题采集快照（`issues/`）、依赖与代码量对照，以及已退役的 V1 迁移说明。
- [`dev-logs/`](dev-logs/)：v2 早期研发与候选提交的阶段性执行流水账（原 `status.md`、`release-readiness.md`）、P2 负载验收协议与代码预算检查点。

## 维护约束

- 归档内容保持历史只读，不随新功能迭代重写或伪造补充；其中包含的历史相对路径或本地证据路径不纳入现行文档链接校验。
- 现行文档不得将本目录作为现行契约依据引用（仅允许在历史注记中说明来源）。
