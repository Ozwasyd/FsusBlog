# 管理标签和文章内容移交

核对了固定 v1 `2605b438eed8f16d12ddddf033d08a6fa18fcd12` 的运行入口和冻结 issue。P3 承接标签管理，P4 保存编辑器、视图及历史中的稳定 ID，P5 承接内容移交。未重跑产品测试。

## 标签的稳定公开坐标

固定 v1 在独立管理身份下注册 `PUT /api/binary/category/{id:int}` 和 `PUT /api/binary/tag/{id:int}`，分别读取 AEDS 33 和 34，要求 `article.write` 和 classic PoW，成功为 EmptySuccess 240。当前有效 payload 在 0–127 保存定长 UTF‑8 name，128/132 是 Description slice 的 LE Int32 偏移/长度，136 是 LE Int32 blob 总长，随后是 UTF‑8 blob，整个请求上限 4096B。描述 trim 后最多 500 个 Unicode 标量，空白持久化为 null。v1 还接受精确 128B 旧请求，PUT 保留既存描述。固定浏览器使用现行格式。新增编码应拒绝名称超出 128 个 UTF‑8 字节，不能切断字符。 [分类 PUT](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Modules/Endpoints/Binary/BinaryEndpoints.Taxonomy.cs#L198) · [标签 PUT](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Modules/Endpoints/Binary/BinaryEndpoints.Taxonomy.cs#L393) · [线布局](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/core/Algorithms/AEDS_V2_PROTOCOL.md#L192)

v1 的标签显示用 Trim+NFC，lookup 再做 invariant uppercase。rename 事务保留旧 lookup alias，防止其他标签复用当前及历史名称。同 ID 可以重新使用自己的历史名称，同归一化名的显示变更无需新 alias。历史 `/tag/{name}` 单跳 301 到稳定 `/tag/{id}` 并保留查询，非法、未知或歧义返回 404。二进制 `/api/binary/tag/by-name.aeds?name=` 返回同一 ID 的现行 exact metadata 243。v2 已映射 `/tag/{name}` shorthand 和 `/tag/{id:int}` canonical，现有列表与 by-name 使用当前和历史 alias。分类没有按名称的此类别名。冻结 #2341 L15 和 #1861 L44–50 要求保存视图继续识别改名实体、明确报告退役。 [v1 alias 事务](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Modules/Endpoints/Binary/BinaryEndpoints.Taxonomy.cs#L955) · [别名验收](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/docs/testing/issue-1087-tag-url-identity.md#L5) · [当前路由](../../src/Server/Content/TaxonomyEndpoints.cs#L61) · [#2341](https://github.com/Ozwasyd/FsusBlog/issues/2341) · [#1861](https://github.com/Ozwasyd/FsusBlog/issues/1861)

v1 名称变化写受影响文章的投影 outbox，随后推进 sitemap、文章列表和分类标签版本，失效相关读、CategoryFrame/TagFrame、HTTP 列表及 PublicHot/AOT；描述变化只更新精确 metadata 与相应 Filter AOT/SEO 路径，sitemap 推进，不追加文章 outbox，不更新列表 frame 和别名。no-op 成功且不失效。v2 现有读快照只用文章 publish/retract/delete 水位触发重建，文章 generation 的 hash 只含发布坐标及关联标签名称。未关联任何文章的标签、描述和 alias 也必须持久触发应有更新；现有 outbox 强制真实文章/修订外键，不能以合成文章记录触发此项。验收覆盖重启、未关联标签、描述专用更新、并发归一化名称冲突和公开单跳。v2 历史修订和别名均有外键，应在明确引用、恢复与重用策略前保留实体及 ID。 [v1 按字段失效](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Modules/Endpoints/Binary/BinaryEndpoints.Taxonomy.cs#L1115) · [v1 失效范围](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Infrastructure/Cache/ICacheInvalidationDispatcher.cs#L394) · [v2 水位](../../src/Server/PublicSnapshot.cs#L185) · [v2 外键](../../src/Migrate/schema-1.sql#L83)
