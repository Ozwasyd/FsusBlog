# V1 离线迁移工具已退役

当前版本不再提供 V1 数据迁移命令。旧源库的盘点、转换、隔离导入、附件和封面准备、历史发布启用，以及账号兼容性审计均不再随仓库维护。不要使用现行的 V2 维护命令连接 V1 源库。

旧演练记录和命令仅作为[历史资料](https://github.com/Ozwasyd/FsusBlog/blob/17bc12fe5a27be200faa9bd32279bcb10ddaf5b0/docs/migration-source.md)保留，不代表当前版本支持旧库导入，也不是生产切换指南。

V2 的建库、结构升级、备份恢复和本地账号管理仍由[离线维护工具](migration.md)支持。退役转换工具不会删除已经迁入的记录；现有的公开历史验证与只读兼容能力不变。
