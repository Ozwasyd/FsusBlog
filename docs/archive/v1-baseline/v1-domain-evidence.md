# v1 服务端功能与数据基线

参考提交为 [2605b438eed8f16d12ddddf033d08a6fa18fcd12](https://github.com/Ozwasyd/FsusBlog/commit/2605b438eed8f16d12ddddf033d08a6fa18fcd12)。静态核对了路由装配、服务、实体和契约文档。表内“已注册”指确认了主应用里的 HTTP 入口，“子系统”指找到服务、契约或存储，仍须核对产品入口或生产资格。阶段号指首个验证点。

| 基线项 | v1 行为、数据和权限 | v2 验收锚点 |
| --- | --- | --- |
| C-01 公开内容 | 已注册首页、归档分页、分类、标签、文章详情、相关文章、四种静态页面和公开配置。分类与标签有稳定数字 ID、名称和可空描述。历史标签名称解析到同一个 canonical。游标绑定列表类型和筛选条件。GET/HEAD 区分真实成功、未公开/缺失和暂不可用。 | P2–P3。匿名首访 HTML 和 AEDS 命中同一公开坐标。私密、缺失或依赖失败不返回成功壳。游标跨筛选拒绝，标签别名一跳重定向，搜索与负响应的 noindex、locale、head 和缓存身份一致。 |
| C-02 文章、发布与历史 | 已注册。文章有 Draft、Scheduled、Published、Archived、Deleted。私有编辑 revision 与公开 publication 分开。发布记录绑定 revision、Rights V3 和可选责任快照。历史支持 CAS 回滚、来源、理由和历史包完整性检查。恢复创建新发布。软删除保留历史并退出公开面，永久删除单独处理活记录和文件。 | P2–P4。作者按预期 revision 写、定时发布、撤回、回滚与恢复。相同幂等请求持久化一次。各公开输出在成功后切到同一发布坐标。撤回或删除后失效，历史包有缺件时保持缺件状态。 |
| C-03 分发、检索、透明度 | 已注册 RSS、Atom、JSON Feed、Sitemap、robots、旧 RSS 订阅地址 /api/Article/rss、订阅/取消及直接查询规范索引的 AEDS Product Search API。浏览器搜索另用静态索引。公开完整性 sidecar 包含签名公钥、发布证明、权利和责任清单、Merkle checkpoint 与透明日志头。管理员可查看和受控重试。 | P2–P3。发布交替时核对索引、canonical、订阅事件与外部分发。撤回后重查公开证明和索引，验证签名密钥与管理员身份字段未泄露。 |
| C-04 媒体与内容工具 | 已注册分片上传的归属、令牌、分片映射、续传、完成/中止与过期清理。媒体有稳定资产身份、授权读取、引用重索引和孤立资产处理。已接通站点内容导出、单篇导出与文章导入，文档转换任务见 E-03。 | P3/P5。完整分片上传可重试。另一身份或错误令牌只得到不可用结果。图片类型、大小和解码边界有拒绝用例。导入后核对引用。孤立资产清理与失败回收只涉及已证明可清理的资源。 |
| C-05 评论与审核 | 已注册文章/线程游标、公开评论和自愿署名。用户侧只查可归属的评论。强匿名资格和运行开关单独判断，管理凭据按单评论隔离。草稿、一次性回执、编辑/删除、状态/申诉、举报及审核历史各有权限边界。审核含区域策略、词典、模型、审计、租约、单条/批量决策和独立申诉。 | P3。以多身份核对可见性、举报去重、审核租约冲突、编辑 CAS 后再审、申诉复核和原文私密性。真实 provider 不可用或凭据过期时正确拒绝。 |
| I-01 普通账号与恢复 | 已注册 PoW 预检、原子 Passkey 注册和 Discoverable Passkey 登录。普通账号是带不透明 subject 的容器，有可选公开 handle、WebAuthn signal、凭据命名/删除、Recovery Key、TOTP 及独立恢复码。可列会话、撤销单设备或其他设备、刷新和注销。另有公开资料、语言偏好及删除。当前实体和迁移目录已经移除旧用户名/密码/用户角色字段。 | P1–P3。真实注册/登录、恢复、刷新和跨设备撤销。普通会话 Cookie 与后台管理隔离。重用、过期或降权后拒绝。公开资料不包含私有身份或设备资料。 |
| I-02 管理员与安全 | 管理员有独立 principal、Passkey bootstrap/login、session、验证代次及 step-up。已注册 PoW、安全挑战、风险策略、反爬、事件审计、策略预览/回退、用户封禁和匿名治理专权。强匿名证明和盲签发有独立资格及 provider 边界。 | P1–P3/P5。作者、审核员、审计员、管理员走正反向权限矩阵。覆盖禁用、越权、过期证明、跨身份/代次和未知状态，验证风险模拟无真实状态变更且策略回退可审计。 |
| A-01 写作与工作区 | 已注册草稿 CAS 保存/读取/放弃、私密结构化预览、发布前检查、修订包与回滚、分类与标签引用统计、资产库和作者分析。另有固定目标的 revision compare、保存视图、文章 pin、最近文章、模板展开和本地 Article Vault 三方计划/执行子系统，非测试入口和产品呈现待逐项确认。 | P2、P4。作者恢复真实会话及草稿。关标签与并发操作保持脏数据，过期身份或不完整历史不应用结果。细查各子系统的实际接入条件和权限。 |
| A-02 属性与 Canvas | 子系统。PropertyDefinition 有 owner/site、CAS 修订、稳定机器键及八种封闭类型。现有权威覆盖定义。私有 Canvas 具备 owner/site、文档修订、五类节点、两类边、命令日志、事务 undo/redo 和引用权限过滤。当前边类型无文章副作用，#3738 对应独立跨业务事务。 | P4。真实属性定义、值和查询贯通。Canvas 重复提交、撤销/重做及切换属主按版本审查，转换按文章与 Canvas 双修订授权。失败回滚双方。 |
| M-01 站内信 | 已注册账号/管理员各自的查询、发送、回复及管理状态流程，包括系统消息和广播。持久模型含内部备注、精确已读游标、未读投影、显式关闭/重开、幂等 mutation 与 outbox。读状态基于快照内最后可见消息。 | P3。两账号与有权限管理员演练新建、回复、已读、关闭/重开及广播。并发追加与内部备注不误读、不泄露，重放不增加消息与未读。 |
| M-02 实时事件 | 已注册 WebSocket /api/notifications/stream 及 preflight，子协议 fsus-aeds.v2。区分公开、会话、路由和对话受众。涉及游标重连、回放、缺口全量同步、慢消费者与服务重启。文章、评论、消息、缓存/索引及安全事件有各自投递策略。 | P3。实际断线测试正常回放与超出保留窗口。账号切换时丢弃旧目标结果，outbox 跨重启或重复投递可恢复。 |
| E-01 平台插件 | 已注册 .fspkg 验包、PostgreSQL 注册表、权限计划、授权、启停/重载/隔离/恢复/卸载、配置 CAS。Jint/Lua Hook 有权限与资源限制。安装权限、运行授权和各节点状态分别判断。 | P5。真实 provider 验证签名、重复 ID、逐项授权和撤销、执行限额、故障隔离、清理与重载，按实际观测呈现节点状态。 |
| E-02 作者扩展、主题与字体 | 作者扩展是独立子系统，有 Worker/Wasm 与外部 provider 隔离、闭合能力、原始授权和事务文档 RPC。权威文档列出尚缺的生产授权/生命周期持久化、同意界面与部分 RPC。主题/字体 registry、activation 和部分 history 管理路由为已注册只读入口。定制 profile/draft/change-set 另有入口。 | P5。逐项核对注册、签名、加载、权限与回退。确认各操作的运行 provider，新增管理操作对应 issue 条款和真实启用证据。 |
| E-03 文档转换 | 子系统。源码定义请求、任务列表、状态、取消、重试、删除、下载处理器及 article.write，主入口未发现 MapBinaryDocumentExportEndpoints 调用。已接通内容/文章导出见 C-04。 | P5。接通真实转换 provider、任务所有权及下载。中止与失败时保留原始错误与拥有资源的清理结果。 |
| O-01 运维与隐私 | 已注册健康、配置、审计、统计、缓存状态/控制、完整性诊断/修复和备份/恢复证据查询。危险操作独立确认与 step-up。阅读证明、匿名聚合和 RUM 各有隐私边界。旧事件级阅读轨迹已退役。 | P3/P5。验证公开健康最小输出、业务权限、审计链和撤权。独立恢复演练核对内容、权限、媒体和密钥，数据库或 Redis 故障有真实结果。 |
| O-02 迁移与集群 | 服务用 current schema verifier 做准入。独立迁移目录有 PostgreSQL/MySQL/SQLite 路径、计划及备份证据。默认单机，源码有 static-role/adaptive 和节点、调度、租约入口，文档列出的支持基线仍是单机。Redis 用于缓存、通知 backlog 和跨节点协调。 | P5。只读盘点、离线写入、备份验证、检查点和重启恢复。逐项报告不兼容凭据/会话。集群失联、租约过期与 fencing 独立验证，单机不依赖跨节点协调。 |

## 源码与文档差异

- 已查的文章写接口要求 article.write，权限目录登记的 article.publish 尚未见于这些写入入口。审计读取使用 audit.read，敏感字段投影上下文检查 audit.investigate。运维健康详情要求 audit.read，运维 UI 路由使用 system.config。v2 需按服务端入口核验读取、写入和敏感操作。 [权限目录](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Infrastructure/Auth/AdminPermissions.cs) · [文章路由](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Modules/Endpoints/Binary/BinaryEndpoints.Articles.cs) · [作者运维路由](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Modules/Endpoints/AuthoringEndpoints.OperationsRoutes.cs)
- 部分已有 authoring 载荷是 AEDS 帧内的 JSON。定制 profile 接口直接返回 HTTP JSON，与 AEDS-only 策略存在差异。v2 应按计划用 AEDS 承载业务及错误，保留各入口的交互与数据语义。RSS、JSON Feed、健康探针、维护工具的标准输出各有独立契约。 [AEDS 策略](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/docs/api/aeds-only-policy.md) · [定制路由](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Modules/Endpoints/CustomizationEndpoints.cs)
- 本地账号、评论、审计、通知和缓存演练有独立开发/测试入口。应将其用作 v2 验收情景的来源，并以配置、真实 provider 和主入口判定可用性。 [路由装配](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Infrastructure/Bootstrap/PublicWebRuntime.cs) · [已知限制](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/docs/known-limitations.md) · [运行模式](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/docs/operations/runtime-modes.md)
