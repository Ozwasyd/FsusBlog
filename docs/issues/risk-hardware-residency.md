## v2 可验证的最小接线

v2 详情先从当前公开快照按文章 ID 取得已生成的托管 HTML/AEDS，发送前复核同一快照，缺失返回 404，当前快照不可用或已替换则拒绝。现存 `PublicResponse` 将同一 `ReadOnlyMemory<byte>` 异步交给 Kestrel。96 MiB 为单个详情缓存的 payload 上限，已有 4 个并行、64 个 pending 的冷渲染接线。现有测试覆盖 64 个等待者共用一次编码与真实 TCP 断开后共享渲染继续。日志可核对四条热路的 Npgsql 与 GC；Unix 文件 API 的 openat/statx 和隔离子进程另有运行证据，均不覆盖设备映射、OS 页锁、NUMA、通用磁盘溢写或独立设备容量。 [详情与发送前复核](../../src/Server/Program.cs#L449) · [发送完成](../../src/Server/Content/PublicResponse.cs#L6) · [缓存预算](../../src/Server/Content/PublicArticleCache.cs#L7) · [原生 Kestrel 否定用例](../../tests/Integration/PublicArticleCacheTests.cs#L34) · [四条热路运行证据](../../tests/Performance/runtime-2026-11-14.md#L5) · [Unix 文件用例](../../tests/Core/NativeUnixFileTests.cs#L7)

首个独立验收可选当前已公开的 AEDS 详情一种表示，沿用原发布 generation、文章/revision/publication 坐标、编码和权限结果。保留托管参考字节，经相同 SQL/HTTP 路径独立核对完整 body 和 headers。同一只读块的相对范围须在已持有资源内，发布变更取消新的 lease，已经在写的请求或提交后的设备操作保留资源直到各自完成。用范围边界、旧代替换、慢消费者、断开以及未获资格和暂时预算拒绝来验证。这个范围可用本地软件实现/验证，作为 #3446/#3447/#3448 与 #3456 的前置证据；真实 OS/驱动、分配/API、NUMA节点、GPU/peer/NIC拓扑和实际消费证据由对应设备环境提供。默认 Auto 仍只采用通过 release/runtime/workload/admission 的路径。当前只有托管参考证据，C4 硬件行保持 NotVerified。 [#3446](https://github.com/Ozwasyd/FsusBlog/issues/3446) · [#3447](https://github.com/Ozwasyd/FsusBlog/issues/3447) · [#3448](https://github.com/Ozwasyd/FsusBlog/issues/3448) · [#3456](https://github.com/Ozwasyd/FsusBlog/issues/3456) · [#3458](https://github.com/Ozwasyd/FsusBlog/issues/3458)
