## v2 缺口与单机候选

v2 首页由公开快照的前十条文章生成，详情、列表和搜索使用公开快照或同代缓存。`Article` 和公开写入器尚未把浏览量写进响应。基线的四路热读零 PostgreSQL 命令只覆盖当时的入口。新阅读采集、聚合、热门 frame、首页接线和旧浏览量来源需要各自验收。 [公开快照](../../src/Server/PublicSnapshot.cs#L36) · [文章模型](../../src/Contracts/PublicArticles.cs#L8) · [公共字段写入](../../src/Contracts/PublicArticles.cs#L264) · [公开热读基线](../../tests/Performance/default-gc-soak-2026-11-15.md#L14)

1. 第一个切片可仅开启当前公开文章的 challenge 和 submit。专用限流、可信浏览器上下文、8 秒可见及 8 秒服务端阈值均保留，票据绑定读取时的发布坐标和用途。文章写入侧锁住发布事实并复核当前坐标，以抵御签发后撤回或改版；v1 入口适配器只委托服务，当前发布的事务内复核是从 v2 发布边界推导的额外约束。站点计数及 `public.read` 风险分需要各自的功能和隐私验收。 [v1 入口适配器](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/backend/Infrastructure/Auth/HumanReadProofEndpointAdapter.cs#L19-L33) · [现有受保护事务](../../src/Server/Operations/InstanceLease.cs#L114)
2. 为统计指定一条长期持有且不复用的物理连接，与实例租约的心跳连接分开。仅该连接可访问 `pg_temp`，其消费记录只含用途隔离摘要及到期桶。使用 `ON COMMIT PRESERVE ROWS` 保留未到期记录，设行数和空间上限，定期删除到期行。建立会话临时表时需确认 `TEMP` 权限；永久聚合 DDL 通过离线迁移。排队、限时或统计依赖不可用时丢弃待处理事件。受保护事务内，短期重放和去重写入与 UTC 小时计数、UTC 日停留分档增量一起提交，批处理按行键排序。只有收到有效提交回执才返回 `counted=true`。 [PostgreSQL 临时表](https://www.postgresql.org/docs/18/sql-createtable.html) · [现有租约](../publication-lease.md)
3. HMAC 签发和摘要密钥只存在于进程内，并绑定实际临时会话与写者世代。连接丢失、租约过期、进程退出或提交结果不明时停止该世代的签发和接收。切换后旧票直接终止，未能确认的提交不进入补写。已确认提交的计数按数据库恢复点保留。若要跨重启延续相同的去重承诺，在旧写者确认停止并取得新租约后保守暂停发票 20 分钟；若业务选择立即重新签发，重启窗口可能对同一阅读者重复计数，需要单列风险与验收。备库恢复期间不读写临时表。升主前隔离旧主库，计划切换验证计数事务 WAL 已回放，获取新租约后再建临时会话。异步灾难升主仍按实际 WAL 恢复点计量。 [现有升主演练边界](../publication-lease.md#postgresql-物理备库演练) · [PostgreSQL 热备限制](https://www.postgresql.org/docs/18/hot-standby.html) · [复制与恢复点](https://www.postgresql.org/docs/18/warm-standby.html)
4. PostgreSQL 临时表数据页不写入 WAL，标准物理 base backup 跳过临时关系，当前 `pg_dump` 调用使用默认命名空间选择。临时关系仍可能落入数据库主机的文件系统，定时清理行也无法提供介质级擦除。部署须排除原始磁盘和内存快照、转储及诊断收集中的该数据，并核对应用、代理和 PostgreSQL 均无请求体、bind 值或 SQL 键值错误详情。若要求标识完全不写到持久介质，候选方案还需要可验收的易失表空间和主机配置。Redis 可另评估显式无持久化的单实例，连同复制、快照、调试和主机转储限制一并验证。独立 Redis 在消费成功到 PostgreSQL 聚合提交之间会产生额外丢失窗口。 [WAL 判定](https://github.com/postgres/postgres/blob/REL_18_STABLE/src/include/utils/rel.h#L576-L599) · [物理备份排除](https://www.postgresql.org/docs/18/protocol-replication.html#PROTOCOL-REPLICATION-BASE-BACKUP) · [PG 18 逻辑备份选择](https://github.com/postgres/postgres/blob/REL_18_STABLE/src/bin/pg_dump/pg_dump.c#L1843-L1868) · [项目备份调用](../../tools/site-backup.py#L246) · [PostgreSQL 绑定参数日志](https://www.postgresql.org/docs/18/runtime-config-logging.html#GUC-LOG-PARAMETER-MAX-LENGTH) · [Redis 持久化与复制](https://redis.io/docs/latest/operate/oss_and_stack/management/admin/)
5. 后台汇总可生成同一发布快照的不可变计数和预编码热门列表。以浏览量、文章 ID 降序，撤回立即排除。每次汇总只推进统计版本，避免重建无关搜索语料。旧浏览量只在离线语义回执保留，真实排行使用新增统计。公开展示历史数值需另定口径。公开命中仍只使用本地字节。
