### PostgreSQL 读取语料前置

`tests/Performance/nightly-run.sh` 定义独占 PostgreSQL 的 `nightly` 与 `pilot` 两种语料。`nightly` 计划 100,000 篇文章和 1,000,000 条评论。80,000 篇普通已发布文章及 5,000 篇等待定时替换的文章仍有公开发布，共 85,000 个公开坐标。另外有 5,000 篇等待首发、5,000 篇撤回和 5,000 篇软删除。撤回使用当前 v2 的原生作者动作。它是单独列出的 v2 分组，固定 v1 的 Archived 兼容仍待验收。固定旧 shell 语料实际产生 77,143 篇公开文章，另无定时替换分组。这里的目标是 canonical 计划的容量与可表示语义，旧 shell、生产图和原 nightly 路由分别举证。

文章写入器按每批 64 篇执行真实的 v2 Save、分类标签、Publish、Schedule、Retract 和 Delete。使用真实修订、命令、权利、发布序列、出站记录和 canonical 坐标。评论用合成化名展示快照加载 500,000 根和 500,000 条回复。热点文章有 20,000 条、最宽 480 个直接回复和 32 层深链。保留隐藏、删除和地区受限祖先，以及已撤回和删除文章的历史评论作为拒绝样本。另留一篇有公开发布且无评论的文章。`pilot` 的 20 篇和 132 条仅用于核对同一路径。

生成、文章写入、评论写入和只读回读分别计时。回读独立比对持久状态、发布和定时坐标、已批准正文与结构占位、评论分布及所选线程和正文摘要。脚本保留本次源、构建、计划、回读摘要、写入 WAL、磁盘和清理证据。两档均是读取语料前置。原 nightly 调度、真实 HTTP 与执行计划的逐请求绑定、完整 FAS4/FSPK、旧评论的身份及治理完整图、跨 provider 对照、失败恢复仍须各自取得证据。 [语料脚本](../../tests/Performance/nightly-run.sh) · [独立 SQL 回读](../../tests/Performance/nightly-verify.sql)
