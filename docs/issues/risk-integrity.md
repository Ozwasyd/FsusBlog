v2 审阅时的独立可交付边界是公钥注册和 JSON 读，不使用私钥、文章/发布数据库行或 outbox。工作树的 `IntegrityKeys.cs` 增加启动时读取、64 条上限、严格 P-256 全 DER 与 Base64URL 校验、显式算法、正版本及日期，未知 current ID 略去。它保留已撤销/泄露的公开元数据，也不保证这些 key 可签可验。与固定 v1 的更严格输入准入及热加载差异明确记入。工作树已加公钥/私钥泄露负例和实际 HTTP 验签测试定义，本轮未重新运行或绑定新候选结果。 [v2 入口](../../src/Server/Content/IntegrityKeys.cs#L18) · [当前验证定义](../../tests/Integration/IntegrityKeysTests.cs)
