# 公开搜索词典与分片的验收

附件 §5.1 和 `V2-006` 要求公开搜索投影使用同一提交的发布坐标并随撤回失效。冻结 #1728 正文 L106–131 要求真实搜索消费 CJK、大小写、重音、混合脚本、长词和标点的精确命中及拒绝用例。#2175 L6、L10–19 另要求独立读取当前 generation、坐标、权利和摘要。词典、FSPT 补丁和分片淘汰的具体能力来自固定 v1 运行代码。冻结档中未定位到独立指定其二进制格式的开放条款；#1765 L7 只限旧响应 wire，C1 仍分别保留公开 FAS4 与本地 FSR4。 [#1728](https://github.com/Ozwasyd/FsusBlog/issues/1728) · [#2175](https://github.com/Ozwasyd/FsusBlog/issues/2175) · [#1765](https://github.com/Ozwasyd/FsusBlog/issues/1765) · [C1](conflicts.md)
