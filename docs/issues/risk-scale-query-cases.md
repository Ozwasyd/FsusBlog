## 固定坐标

- 文章语料共 100,000 篇。独立预期集合是普通公开 ID 1–80,000 与待更新 ID 85,001–90,000，合计 85,000 篇。公开版本全为修订 3，待更新编辑头为 5。定时首发 80,001、管理员归档 90,001、作者删除 95,001 为首个对应反例。独立 PostgreSQL 读回必须在真实 scope 的发布、revision、rights 与 taxonomy 坐标上重算顺序。按 `a.created_at DESC,a.id DESC` 对**实际**时间以微秒精度排序，再封存排名中的 ID 和 publication/revision。生产 writer 每 64 篇事务内用 `now()` 写默认创建时间，存在真实并列，禁止以输入 ID 顺序或 HTTP 解码的毫秒时间重排。已公开的旧修订要使用自身的标题、正文和 taxonomy，排除定时或归档编辑头。下文 `A[n]` 为独立读回的第 n 名，从 1 起算。 [计划样本](../../tests/Performance/nightly-plan.py#L35) · [真实写入批次](../../tests/Integration/NightlyFixturePostgresTests.cs#L75) · [默认时间](../../src/Migrate/schema-1.sql#L30) · [读回和坐标](../../tests/Performance/nightly-verify.sql#L251) · [生产快照](../../src/Server/PublicSnapshot.cs#L264)
- 分类 1 是最大分类，计划应有 42,500 篇。标签 1 是最大标签，计划应有 15,937 篇。可另解码类别/标签集合帧 9/10 核对成员总数，帧 243 只提供单项元数据。分类 32 与标签 128 是已存在的空坐标，初始化固定 32/128 个目录项，分配表达式最高只引用 31/127。全计划公开成员的计算显示其余各 ID 都有成员。实库仍须确认最大值、所有桶及已存在且无公开关联，不以找不到的 ID 或按当前响应临时挑选代替。每个桶沿 `A` 顺序取成员。 [分配](../../tests/Performance/nightly-plan.py#L47) · [创建真实目录](../../tests/Performance/nightly-run.sh#L95) · [公开成员投影](../../src/Server/Content/TaxonomyEndpoints.cs#L87) · [集合编码](../../src/Contracts/TaxonomyWire.cs#L14)

导出的独立预期至少绑定 fixture 和 readback 摘要、业务时间及当前公开坐标。文章流按排名写 ID、实际时间、revision/publication、taxonomy IDs 和正文 SHA-256，评论流写十进制 ID、parent/root/depth、原可见性和预期公开内容或占位标记。为每个 case 封存页号或期望前页锚点、全数、预期目标行和前缀摘要。读回可按有序游标流式消费，无需把正文或所有查询响应收进单个 JSON。HTTP 实际结果只用于对照。

## 16 个用例

以下 GET 使用正常匿名端点和当前发布代次。文章页宽沿用历史值 10。历史评论页宽为 1，v2 根/子端点将输入限制为至少 5，因此本切片显式用 5。两种布局的原样比较仍待明确接受，不能通过发送 `limit=1` 暗中得到 5。评论序号 `n` 表示根 ID `B+n`。

## HTTP、SQL 和资格输出

- 逐个响应校验 AEDS v2 的 magic、16 字节头、类型、长度、CRC、`application/octet-stream` 及完整字节。文章列表用帧 1／FSPA v2／100 字节记录，详情帧 2／ARD5，搜索帧 4／FAS4。历史 detail 路径误漏 `.aeds`，v2 使用生产路由后缀。FSPA 的 total、当页成员、旗标/长度和终态都要解码。文章第 1 页无 token，之后每页使用上一页返回的 155 字符 AEAD Base64URL token，加序号及 scope、当代、size、sort/keyword 和锚点。每次签发 15 分钟有效，绑定当前进程。home/archive、评论与 FAS4 的 query policy 有 32 个并发名额、零等待，超限 429，按并发而非每秒计数。taxonomy 单独走自己的路由。第 8,500 页至少需要上一链 8,499 个合法响应；记录真实进程、上下行游标及拒绝，保留 429、已换 generation、超期和中止。各目标 HTTP 观测分别记录，若共用真实前缀应引用同一证据且分开记录 warm/cold 影响。保持生产门槛，不生成手工 token、不绕过 limiter 或用 SQL OFFSET 当续页。 [AEDS](../../src/Contracts/Aeds.cs#L14) · [结构版本](../../src/Contracts/wire.schema.json#L644) · [注册路由](../../src/Contracts/wire.schema.json#L189) · [历史详情错误](https://github.com/Ozwasyd/FsusBlog/issues/1640#issuecomment-6053329791) · [游标](../../src/Server/PublicListCursor.cs#L61) · [生产限流](../../src/Server/Program.cs#L105)
- 评论根/子/上下文/线程分别用当前帧 208/209/210/8。根头为 i64 next、1 字节旗标、i32 count；子头为 i64 parent/root/next、i32 count/flags。八字节 ID 和 next 用小端有符号 64 位，HTTP cursor 用正十进制 i64。根严格小于锚且降序，子和线程严格大于锚且升序，最终 `next=0/flag=0`。根页应沿真实响应游标验证完整成员与无重复；末页目标的当前实现需要前缀 1,999 页。上下文无 cursor，window 2–20。归档和删除的评论路由由快照拒绝读取，返回协议空响应，不做 PG 数据语句；公开空文章 2 仍走实库。当前评论路由无对外 generation header，绑定实际每请求的快照需要独立观测，不能只利用其他端点的单次头部。 [评论路由和范围](../../src/Server/Comments/CommentReadEndpoints.cs#L13) · [私有文章及数字游标](../../src/Server/Comments/CommentReadEndpoints.cs#L88) · [帧](../../src/Contracts/CommentReadWire.cs#L19) · [SQL](../../src/Server/Comments/CommentReadStore.cs#L52)
- foreground 所有权。普通列表和 taxonomy 用当前内存排序/匹配及快照字节，detail 走快照的托管字节或冷渲染，FAS4 走同代倒排索引；这些路径都没有请求 SQL。记录归因至请求的 Npgsql 零调用、代次、字节、延迟、实际快照/托管索引 owner。后台快照读回是另有归属的独立 PostgreSQL 操作。评论中的非空根页使用 repeatable-read 只读和实际 2 秒语句期限。根有 page＋preview 两条数据语句，children 有 parent＋page、context 有 path＋neighbors、thread 一条数据语句；进入事务还有一条配置命令，找不到 parent/target 少一条数据语句。收集正常目标请求的实际 SQL 和 typed parameters、fingerprint 及同一 fixture 和 business epoch 的 `EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON)`、行数、共享块、temp 和实际索引。关联缺失时留缺证。当前 P2 观测器只把根评论单列，子项、上下文、线程、taxonomy 和 FAS4 落入 `otherHttp`，需用独立请求观测而非共用 P2 热路汇总。 [当前归因](../../src/Server/Operations/RuntimeEvidence.cs#L107)对于无 SQL 的路由，保留无 SQL 观测，仍须为 v2 的非 SQL 查询层冻结与之对应的执行和预算判据，旧 evaluator 的缺 plan 检查保持原失败。 [列表遍历和深锚算法](../../src/Server/PublicListProjection.cs#L25) · [taxonomy](../../src/Server/Content/TaxonomyEndpoints.cs#L87) · [详情快照](../../src/Server/Program.cs#L449) · [评论事务](../../src/Server/Comments/CommentReadStore.cs#L130) · [历史收集验证](https://github.com/Ozwasyd/FsusBlog/blob/6d7c648f3d879d985352ff633426c49f1539e5a9/tools/data-scale/query-matrix.mjs#L184-L264)
