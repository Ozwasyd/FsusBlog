待决项：

- #1917 的扩展类型如直接进入文章 schema，会打破 #1860/#2322 的跨栈封闭类型。可以评估把受控 codec/验证器限制为已有类型适配，或由独立版本化边界允许新类型；两条路径在 schema、签名信任、查询投影与迁移上有不同影响。现阶段内建八种类型的实现不能作 #1917 完成证据。
- #1871 的双向 Vault 与 #1856 的服务端独占工作区快照适用于不同对象。前者允许本地 Markdown 内容副本，不赋予布局、发布、身份或权限的本地写入权。
- #3468 中的 PublicAOT 指公开页面构件和快照边界。它不改变“不把 .NET NativeAOT 作为首交硬目标”的决定；内存 epic 的功能和硬件覆盖仍待专门裁决。
