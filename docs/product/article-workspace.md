# 文章工作区

打开、激活、固定、关闭和恢复共用 `WorkspaceRegistry`。标签从 registry 投影，路由负责导航。同一文章在工作区内只有一个会话。通过标签、文章 ID 入口和浏览器前进后退切换时，真实草稿读取或已有会话校验完成后才激活，失败则标记不可用并保留当前编辑。新浏览器标签使用独立路由，不向原工作区注册。

预览只会替换同组内已有且干净的预览。编辑和显式固定都会固定标签。切换回来会重新检查授权和持久化修订，有新修订时保护本机内容并显示冲突。关闭含未确认内容的标签需要确认。待处理请求禁止直接关闭。最近关闭仅保存最多 12 条同账户的文章 ID 和固定模式，重新打开要加载当前授权的草稿。

从文章管理的「工作区」或编辑页的「Open saved workspace」进入默认工作区。服务器按当前数据库站点和作者保存一个布局，两组共可保存 100 篇已保存文章的组内顺序、固定或预览状态、各组当前文章和焦点组。写入使用同一个 CAS 修订。另一浏览器已提交新布局时保留本页的编辑与临时布局，并提示重载。重新进入时逐篇验证当前草稿后才创建标签，删除或不可见的文章会跳过。焦点文章不可用时可回到另一组仍有效的当前文章。 [#1856](https://github.com/Ozwasyd/FsusBlog/issues/1856)

现有部署可停机运行 `authoring-workspace` 添加分组存储，保留原单组顺序、Inspector 开关和修订。服务器通过 v3 工作区协议保存两组。同一记录为双组时，旧协议读取与写入都返回 `409`。旧部署仍可保存原单组布局，第二组留在当前浏览器标签内。Inspector 在宽屏以侧栏恢复，窄屏以 FsusUI Drawer 恢复，视口变化沿用同一个开关。刷新或重开恢复最近一次已获服务器确认的布局。

桌面按活动标签位置投影最多 24 个标签，溢出每页最多 12 个，375px 下使用当前文章切换器。键盘以 Arrow、Home、End 移动焦点，以 Enter 或 Space 激活。Delete 和中键请求关闭。取消关闭后焦点返回原控件。当前 registry 最多容纳 100 个会话，界面最多挂载两个选中的 FsusUI 编辑器。

已打开一篇文章时，可在「Article ID」输入另一篇文章并选择「Open in other group」。已有文章会回到原组。空间充足时，两组并排显示各自的 Markdown 源码，只有焦点组可以编辑。可用宽度低于 59 rem 时收起另一组，仍可从「Article groups」切换。宽度恢复时先重新校验另一组的草稿权限。两组保留原编辑器实例，焦点切换和视口收起不会重新挂载。 [#1855](https://github.com/Ozwasyd/FsusBlog/issues/1855)

离线期间的布局变化保留在当前浏览器标签，恢复联网后仍需重新加载已保存的工作区才继续同步。未确认的草稿内容继续由草稿恢复处理。打开与关闭的保护仍由原会话处理，双组提供源码编辑和普通粘贴。可调比例、移组与合并、双组富预览、Rail 布局偏好、Inspector 内部视图和完整编辑器挂起仍待交付。

固定 v1 提交的标签栏位于编辑区之前，窄屏只显示当前标题和切换入口，标签不展示文章详情。v2 保留这些关系和交互。v1 另有 Rail、Quick Switcher 和跨组布局合同。 [v1 标签组件](https://github.com/Ozwasyd/FsusBlog/blob/2605b438eed8f16d12ddddf033d08a6fa18fcd12/src/frontend/src/components/admin/article/ArticleWorkspaceTabStrip.vue) · [#2295](https://github.com/Ozwasyd/FsusBlog/issues/2295) · [#2296](https://github.com/Ozwasyd/FsusBlog/issues/2296)

编辑页的「Article library」使用与作者文章管理相同的权限查询，每页取 20 条元数据。可按标题与发布状态筛选。活动文章按文章 ID 标记，即使不在当前结果页也会单独查找并显示。双向箭头和 Home、End 在结果间移动焦点。Enter 使用当前工作区的同一打开命令，Ctrl 或 ⌘+Enter 在独立浏览器标签打开。桌面面板不会改变正文宽度，窄屏使用本地 FsusUI Drawer。关闭后焦点返回入口。全文模糊排序、分类与标签筛选、布局偏好持久化及 10,000 篇浏览器规模验证仍待完成。 [#1853](https://github.com/Ozwasyd/FsusBlog/issues/1853) · [#2231](https://github.com/Ozwasyd/FsusBlog/issues/2231)

「Recent opens」显示当前站点和作者主动通过工作区标签、文章 ID、Article library 或最近关闭打开的已保存文章。路由完成且活动编辑会话持有服务器见证的草稿修订后才提交。服务器复核当前会话、所有权、草稿修订和历史修订，按提交序号倒序，每篇文章保留最近一条，最多保留 1,000 篇及 1,000 个幂等回执。每页 20 条，翻页时校验历史修订。回执未被淘汰时原命令可幂等重试。淘汰后旧命令的历史修订不能覆盖新记录。查询仅返回仍归当前作者且未删除的文章，顺序不随标题或保存时间改变。账号无记录时显示空列表。 v2 的撤回稿仍归作者，可再次打开。 [#2230](https://github.com/Ozwasyd/FsusBlog/issues/2230)

直达链接、浏览器新窗口、前进后退、工作区恢复及草稿保存不计入当前打开历史。离线打开不排队回写，CAS 冲突不自动重放旧动作。老数据库停机运行 `author-recent-opens` 后启用此视图。编辑历史、外部审计摘要、独立校验器及跨组导航仍待交付。

编辑器使用本地 FsusUI 的公开 `documentIdentity`。每篇文章保留正文、修订和未保存状态。已经换下的编辑器再次显示时可能需要重新挂载。完整挂起及恢复仍需可验证的编辑器快照接口。 [#2294](https://github.com/Ozwasyd/FsusBlog/issues/2294)

Registry 单元验证覆盖 100 会话、组内预览替换、异步加载失效、跨身份退回、权限撤销、远端修订冲突及最近关闭容量。单独使用 Chrome 验证了 33 条标签投影的桌面和溢出上限、键盘焦点、固定和窄屏切换。当前环境未提供 Browser 技能，本机测试使用项目的 Playwright 和已安装的 Chrome。

原生 PostgreSQL、Kestrel 与 Chrome 联合测试通过实际延迟草稿响应、找不到文章、预览替换、固定标签保留未保存文字、键盘与浏览器历史、375px 窄屏、取消关闭后焦点、最近关闭重开及独立浏览器标签。服务与数据库清理通过。 [本机浏览器证据](../../artifacts/workspace-combined-20261114-scoped/browser-result.json)
