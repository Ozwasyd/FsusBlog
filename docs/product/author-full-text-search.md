# 作者全文搜索

作者从文章管理打开「作者全文搜索」，可以查找当前可编辑文章的标题、已保存摘要、完整 Markdown 正文和章节标题。普通词和双引号短语可组合，所有查询子句都必须命中。短语要求同一字段中的词元相邻。`field.title:`、`field.summary:`、`field.markdown-body:` 和 `field.heading:` 分别限定紧随其后的词或短语。章节标题由 FsusUI 的 Markdown 语法解析器识别，包括 ATX 和 Setext，围栏代码内的 `#` 行仍属于正文。同一章节标题子句的词元必须来自同一个标题。空摘要产生零个摘要词元。查询最多八个词元，拒绝未知字段语法、正则和运算符。文本使用 NFC → Unicode 17.0 默认简单折叠（C／S）→ NFC，保留源文本的 UTF-16 和 UTF-8 半开区间。大小写折叠表固定于 Unicode 17.0，NFC 和字素边界由部署的 .NET 全球化运行库计算。CJK 和 emoji 可按独立字素命中。短语片段高亮第一个命中词。

同一文章每个子句的最佳命中按标题 10 分、章节标题 6 分、摘要 4 分、正文 1 分计。依次按短语权重降序、全部子句权重降序、文章更新时间降序和文章 ID 升序排序。每页最多 20 篇。续页游标绑定原查询字符串、作者和当前浏览器会话、当前服务实例以及索引来源的文章 ID、修订和排序时间。游标有效期为 15 分钟。来源变化后，原查询应从第一页重新执行。结果链接打开编辑器。「跳到命中位置」会重查生成该命中的同一页，并通过现有编辑工作区打开核对过的保存修订。文章标题和摘要选中命中词，正文和章节标题的光标落在 Markdown 原文命中词的起点。

全文查询可以加上 `status:draft`、`status:scheduled`、`status:published` 或 `status:retracted` 中的一项，并按 `category:12`、`tag:34` 这样的数字 ID 限定分类和标签。每种筛选项最多出现一次。至少保留一个词或短语，所有筛选和文本条件按交集匹配。管理员归档由独立的归档预览入口授权。

搜索面板还可按文章更新时间和已启用筛选的类型化属性限定结果。更新时间以 UTC 计，包含起点和排除终点。属性查询最多四项，沿用文章属性筛选的类型、定义修订、比较规则和引用权限。文本、更新时间和属性条件共同决定命中、总数和现有分面。

结果总数与状态、分类、标签计数来自应用全部筛选后的同一批匹配文章，翻页沿用这一范围。状态计数包括零。每个分类或标签桶统计匹配文章数，依次按计数降序及 ID 升序取最多 12 项。界面注明是否还有其他桶。返回的数据沿用文章当前修订的分类标签关系和实时名称。任一查询相关状态、分类归属、标签归属或名称更改都可使原分页失效。

属性分面可从已启用筛选的布尔、单选、多选定义中选择一个。计数与其他分面使用同一批匹配文章，明确区分未设置、显式空值、布尔 `false` 和空多选集合。活动选项按稳定 UUID 对应当前定义，每篇文章在同一选项只计一次。多选分面的各选项可以共享文章。带分面的查询用 `33022` 和 `33023`，续页在无其他属性条件时也核对定义和属性值修订。分面操作使用现有筛选条件。

排序可选择已启用 `Sortable` 的文本、数字、布尔、日期、单选或多选定义。有效值按选定方向比较，显式空值、未设置和不可用值依次置后。文本按固定字节顺序比较，数字使用精确十进制，多选以规范选项 UUID 序列比较。同值沿用相关性、更新时间和文章 ID 规则。排序可与现有分面和章节查询组合，使用 `33026` 与 `33027`。游标绑定定义和值修订，保存同一结果集中的文章位置。

全文范围可选一个已启用 `SearchEligible` 的文本定义。索引读取实际保存的属性值，复用文章全文的分词和原始坐标规则。缺失、显式空值和空文本无词项。状态、分类、标签、日期和类型化条件仍按交集过滤。`33029` 和 `33030` 绑定被选定义、架构版本和当前值。点击属性命中的「跳到命中位置」时，搜索重放原页后用 `33034` 锁定命中对应的现行属性值修订。编辑器重读同一修订，校验原文摘要和 UTF-8、UTF-16 区间后，在 FsusUI 检查器的属性输入中选中原文。两次精确读取期间的属性变更会取消定位，已锁定的值即使改回相同文本也需要重新选择。

选中文本属性后，也可同时使用类型化排序、属性分面、日期和筛选条件。`33035` 与 `33036` 复用同一授权匹配范围。分面统计筛选后的整组文本命中，续页同时核对文本来源和排序、分面使用的属性版本。实库验证页外排序值变化使旧游标失效。375px 界面会重放同一带排序和分面的搜索请求，再打开属性的精确位置。

在已选文本属性时勾选「同时匹配文章字段」，可用 `field.property:` 和文章字段词组成同一个查询。两类条件均须满足，例如 `field.heading:航线 field.property:"审阅 完成"`。`33040` 与 `33041` 在同一批有权文章上计算排序、分面和分页，且要求两路索引均已就绪。游标和命中回读同时复核文章与属性来源。精确片段来自当前最高优先级的匹配字段。

`POST /api/v2/authoring/full-text/search.aeds` 的浏览器常规查询使用 `33018` 请求和 `33019` 响应，支持摘要、分面、更新时间和属性。显式 `field.heading:` 查询使用 `33020` 和 `33021`，继承现有筛选，未指定字段的其他子句可匹配四种字段。旧查询帧 `33006`、`33010`、`33013` 和 `33015` 沿用标题与正文范围。服务器锁定当前作者权限并核验 `X-Fsus-Current-Session`。库内由同一站点的当前文章、所有者和不可变修订提供内容权威。索引记录字段的 SHA-256、精确词元及位置。只为同一所有者且现行可编辑的文章返回片段。服务器从当前绑定修订读回原文并核对摘要与区间。结果发送前再次核对文章修订和归档状态。用属性筛选时，续页还核对定义、文章属性修订和引用目标的发布与权益状态。

每次查询首页时，服务器按文章 ID 对账最多八个变动文档。文章来源每批处理的原文不超过 250,000 个 UTF-16 单元。索引覆盖还不完整时，响应只报告准备中，并在同一 PostgreSQL 事务中保存按作者与索引范围去重的补齐任务。后台使用现有索引写入路径，每次提交一批，核对数据库租约、作者权限代次及所选属性定义；重启后自动断点续建已提交批次。刷新查询首页可检查就绪，游标仍由实际源修订校验。章节标题超出单篇解析预算时回滚当前批，停止该任务的自动重试（章节查询报告 `422`，常规全文查询继续可用）。所需索引与补齐任务表结构随 `FsusBlog.V2.Cli` 统一的 `plan` / `apply` 初始化。

查询按作者、词元和文章键检查候选范围内的倒排记录，再按词组与字段规则取每个子句的最佳命中，每页最多返回 20 条且仅在选中具体命中跳转时才读取文章草稿全文。

定位交接在当前浏览器页面内存中一次使用，浏览历史只携带临时随机值。编辑器核对当前会话、文章修订、命中字段全量摘要、原始 UTF-16 和 UTF-8 范围，以及实际控件焦点和光标或选区。正文字段在 LF 或统一 CRLF 下定位。草稿尚有本地恢复选择、未保存或待重试写入，或当前会话或导航已变化时，搜索定位取消。核对成功的显式定位才计入最近打开。

原命中的保存修订变更时，搜索先刷新结果。刷新页仍包含同一文章的更新修订时，可以显式打开「查看原保存修订的命中位置」。该操作再次核对更新修订，再从历史权限入口读取早期的保存内容，在只读弹窗选中原命中。标题、摘要、正文和章节标题都用原摘要和坐标核验。工作区继续使用当前草稿。

正文命中可跨最多八个相邻保存修订重新定位。每版最多记录八次经 FsusUI 验证的显式插入、删除或替换。服务端用不可变正文回放有序操作，将验证过的坐标、两端摘要和保存修订一同提交。没有操作记录且字节相同的正文可以跨过对应修订。重新定位会核对当前会话、链上摘要和原文区间，再由 FsusUI 逐步映射。操作触及命中、缺少可靠记录或编辑存在歧义时，可显式查看原保存修订定位。

文章管理和属性筛选中的标题／摘要条件读取当前保存的手动摘要，未填写时使用现有正文摘录。手动摘要通过文章编辑器检查器保存，每次提交都会创建新修订；普通保存保留摘要，历史恢复沿用来源修订的摘要，公开列表使用已发布修订对应的摘要。

验证入口：`tests/Integration/AuthorText*PostgresTests.cs`。全文索引未就绪时仅返回准备状态。
