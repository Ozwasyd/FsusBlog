# 作者全文搜索

作者从文章管理打开「作者全文搜索」，可以查找当前可编辑文章的标题和完整 Markdown 正文。裸词按交集匹配，命中词可分布在标题和正文。整条查询用双引号包围时，同一字段的词序必须连续。首版使用 NFC → Unicode 17.0 默认简单折叠（C／S）→ NFC，保留源文本的 UTF-16 和 UTF-8 半开区间。大小写折叠表固定于 Unicode 17.0，NFC 和字素边界由部署的 .NET 全球化运行库计算。CJK 和 emoji 可按独立字素命中。每次最多八个词元，未知字段语法、正则和运算符会被拒绝。短语结果高亮首个命中词。结果按文章 ID 倒序，最多 20 篇，超出时提示截断。结果链接打开文章编辑器。

`POST /api/v2/authoring/full-text/search.aeds` 使用 `33006` 请求及 `33007` 响应。服务器锁定当前作者权限并核验 `X-Fsus-Current-Session`。库内由同一站点的当前文章、所有者和不可变修订提供内容权威。索引记录正文和标题摘要、精确词元及位置；公开快照和浏览器缓存没有私有索引语料。只为同一所有者且现行可编辑的文章返回片段。服务器从当前绑定修订读回原文并核对摘要与区间。结果发送前再次核对文章修订和归档状态。

作者首次提交搜索或保存新修订后，服务器按文章 ID 处理最多八个变动文档，每次处理的原文不超过 250,000 个 UTF-16 单元。每批在同一 PostgreSQL 事务替换索引。索引覆盖还不完整时，响应只报告准备中，可继续同一次查询。稳定读取校验文章头和持久索引的一致性，再查倒排记录，只读取命中的原文。对账以当前文章头及原有修订为准，也覆盖批次期间晚提交的文章写入。提供的迁移命令 `author-search` 应停服执行，现有库可以不安装；新库包含索引结构。

这里使用独立的内容搜索入口。文章管理的标题／前 200 字摘要与类型化属性筛选继续使用原有集合筛选。全文搜索首版范围包括当前标题及正文、普通词及单短语、私有授权和索引对账。原计划的标题层级定位、分类／状态／属性 AST、相关性排名、分面、续页、精确跳转和 10,000 篇验收仍待完成。全文索引未就绪时不会返回旧语料或调用集合筛选。
