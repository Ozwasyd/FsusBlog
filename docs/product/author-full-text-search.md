# 作者全文搜索

作者从文章管理打开「作者全文搜索」，可以查找当前可编辑文章的标题和完整 Markdown 正文。普通词和双引号短语可组合，所有查询子句都必须命中。短语要求同一字段中的词元相邻。`field.title:` 和 `field.markdown-body:` 分别限定紧随其后的词或短语。查询最多八个词元，拒绝未知字段语法、正则和运算符。文本使用 NFC → Unicode 17.0 默认简单折叠（C／S）→ NFC，保留源文本的 UTF-16 和 UTF-8 半开区间。大小写折叠表固定于 Unicode 17.0，NFC 和字素边界由部署的 .NET 全球化运行库计算。CJK 和 emoji 可按独立字素命中。短语片段高亮第一个命中词。

同一文章每个子句的最佳命中按标题 10 分、正文 1 分计。依次按短语权重降序、全部子句权重降序、文章更新时间降序和文章 ID 升序排序。每页最多 20 篇。续页游标绑定原查询字符串、作者和当前浏览器会话、当前服务实例以及索引来源的文章 ID、修订和排序时间。游标有效期为 15 分钟。来源变化后，原查询应从第一页重新执行。结果链接打开编辑器。「跳到命中位置」会重查生成该命中的同一页，并通过现有编辑工作区打开核对过的保存修订。标题选中命中词，正文光标落在命中词的起点。

全文查询可以加上 `status:draft`、`status:scheduled`、`status:published` 或 `status:retracted` 中的一项，并按 `category:12`、`tag:34` 这样的数字 ID 限定分类和标签。每种筛选项最多出现一次。至少保留一个词或短语，所有筛选和文本条件按交集匹配。管理员归档由独立的归档预览入口授权。

搜索面板还可按文章更新时间和已启用筛选的类型化属性限定结果。更新时间以 UTC 计，包含起点和排除终点。属性查询最多四项，沿用文章属性筛选的类型、定义修订、比较规则和引用权限。文本、更新时间和属性条件共同决定命中、总数和现有分面。

结果总数与状态、分类、标签计数来自应用全部筛选后的同一批匹配文章，翻页沿用这一范围。状态计数包括零。每个分类或标签桶统计匹配文章数，依次按计数降序及 ID 升序取最多 12 项。界面注明是否还有其他桶。返回的数据沿用文章当前修订的分类标签关系和实时名称。任一查询相关状态、分类归属、标签归属或名称更改都可使原分页失效。

`POST /api/v2/authoring/full-text/search.aeds` 的分面查询使用 `33013` 请求。加入更新时间或属性时使用 `33015`，两者响应均为 `33014`。`33010`／`33012` 提供既有排名和分页，`33006`／`33007` 提供原查询语法、文章 ID 倒序以及截断标记。服务器锁定当前作者权限并核验 `X-Fsus-Current-Session`。库内由同一站点的当前文章、所有者和不可变修订提供内容权威。索引记录正文和标题摘要、精确词元及位置。只为同一所有者且现行可编辑的文章返回片段。服务器从当前绑定修订读回原文并核对摘要与区间。结果发送前再次核对文章修订和归档状态。用属性筛选时，续页还核对定义、文章属性修订和引用目标的发布与权益状态。

作者首次提交搜索或保存新修订后，服务器按文章 ID 处理最多八个变动文档，每次处理的原文不超过 250,000 个 UTF-16 单元。每批在同一 PostgreSQL 事务替换索引。索引覆盖还不完整时，响应只报告准备中，可继续同一次查询。稳定读取校验文章头和持久索引的一致性，再查倒排记录，只读取命中的原文。对账以当前文章头及原有修订为准，也覆盖批次期间晚提交的文章写入。提供的迁移命令 `author-search` 应停服执行，现有库可以不安装；新库包含索引结构。

定位交接在当前浏览器页面内存中一次使用，浏览历史只携带临时随机值。编辑器核对当前会话、文章修订、命中字段全量摘要、原始 UTF-16 和 UTF-8 范围，以及实际控件焦点和光标或选区。正文字段在 LF 或统一 CRLF 下定位。草稿尚有本地恢复选择、未保存或待重试写入，或当前会话或导航已变化时，搜索定位取消。核对成功的显式定位才计入最近打开。

文章管理的标题／前 200 字摘要与类型化属性筛选使用现有集合筛选。原计划的摘要和标题层级搜索、属性值分面、历史或重定位跳转和 10,000 篇验收仍待完成。全文索引未就绪时只返回准备状态。
