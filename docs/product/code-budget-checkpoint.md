以当前分配的上界计算为 200,391 NCLOC，保留 8,155 NCLOC 容差。缺失来源、尚未裁决的冲突和未发现的跨仓归属可能占用容差。下一次复估在独立管理员认证、复杂工作区操作和代表性生产转换路径经过原生验证后进行。最终需从精确发布候选复核 FsusUI 引用差异和自有代码归属，再计算同等功能口径下的减量。现有切片的比率不用于判定 90% 目标。
