# 界面语言

博客公共界面、登录流程、作者工作区和管理员页面支持简体中文（`zh-CN`）和英文（`en`）。作者工作区从页眉的语言选单切换；管理员页面在其独立站点右上角切换，不与博客跨域共享偏好。文章、评论、分类名称及站点政策正文均保留发布者提供的原文。

语言切换写入站点自己的 `fsus_locale` 偏好 cookie，并立即更新界面，不重新加载页面。首次访问按请求的 `Accept-Language` 优先级选择支持的语言，无法匹配时用简体中文。浏览器采用服务端在 HTML 中标记的语言，避免首次挂载时换语言。

新文案加入 `src/Contracts/site-locales.json` 的两个语言字典。公共 HTML 为两个语言预生成独立表示，并通过 `Content-Language` 和 `Vary: Cookie, Accept-Language` 区分；带 ETag 的站点政策页使用各自的验证值。语言偏好不影响二进制数据接口。

作者与管理界面的词条放在 `src/Web/src/workspace-locales.json`，只在进入相关页面时加载。用户输入、原始服务器诊断及协议标识保持原样。
