# 文章分类和标签

匿名读使用发布快照中的分类、标签、名称与文章关系。列表 AEDS 帧沿用 v1 的 `CategoryList`（9）、`TagList`（10）和 `TaxonomyExactMetadata`（243）。分类与标签计数基于当前公开文章。编辑后的草稿仍可保存另一组分类标签，直到明确发布该修订。首页、归档、分类和标签使用相同的签名游标规则。标签名称入口按 Unicode NFC 和不区分大小写的名称或别名匹配，保留 query 并单跳重定向到 `/tag/{id}`，歧义或缺失返回 404。

文章所有者可以在编辑页打开已保存的草稿，然后保存一组分类标签。每篇文章可选一个分类和最多 32 个唯一标签。服务端在同一个事务里确认当前会话和所有权，比较草稿修订，写入新修订并记录幂等结果，再提交变更。新修订保留草稿标题和正文。表单收到原命令重放时会得到相同修订。旧修订、未知条目或越权身份不会写入。普通保存、Canvas 插入和发布会把现有分类标签带到新修订。

`GET /api/v2/authoring/draft/{id}/taxonomy.aeds?revision=…` 返回 `DraftTaxonomy`（32790）。`POST /api/v2/authoring/taxonomy/assign.aeds` 接收 `TaxonomyAssignment`（32791）并返回 `DraftTaxonomy`。帧以分类 ID `0` 表示未分类。标签数组由 `int32` 数量和对应的 `int32` ID 构成，读响应按 ID 升序。关联存储带有指向文章修订、分类和标签的 PostgreSQL 外键。运维导入需要同时保存已发布修订和草稿修订的关联。

实库测试覆盖公开快照、旧名重定向、修订级授权、幂等、冲突、未知分类回滚、撤回和旧游标失效。分类与标签预置通过离线数据导入或测试语料，管理员创建、重命名和删除仍待 v1 权限及 PoW 边界接入。
