# Public Layout Rules

## Mobile Navigation

AccountLayout uses the FsusUI section 8 scrollable tab strip pattern for mobile account navigation.

- Primary group tabs render as a horizontal scrollable tab strip.
- Each tab and account route link uses a 44px minimum hit target.
- When more than five account groups are available, the first five remain visible and the remaining groups are collected behind a "更多" tab strip expansion.
- AccountLayout must not use drawer navigation for its primary mobile account menu.
