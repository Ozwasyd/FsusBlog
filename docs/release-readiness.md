# 发布验收仍需验证的边界

目前的 Git 历史包含可运行的 v2 和多次独立候选。每项证据只适用于对应提交、配置、工具链和输入。最终发布需要从同一冻结提交复验各域并证明完整性。

| 验收项 | 已验证的范围 | 发布前仍需完成 |
| --- | --- | --- |
| 公开发布与读取 | 实库和 Chrome 覆盖保存、CAS、发布、撤回、定时发布、权利快照和 outbox 恢复。已实测管理员向公开版本回滚、租约交接、冷读限制、同代索引和标准订阅源。两套 PostgreSQL 升主验证旧实例拒绝、原发布读取与幂等重试。当前原生发布支持权利摘要、签名和 FsusUI 现场验签。 | 回滚到草稿和归档、历史责任及透明度、热度、FSPT 索引补丁、生产集群编排与重新入组。 |
| 身份与授权 | 双 HTTPS 主机覆盖独立管理员 Passkey、独立审计权限、Cookie 隔离、来源拒绝、当前授权展示和仅自己可见的近期成功登录。账号 TOTP、一次性恢复码及重生成、Recovery Key 重绑 Passkey、会话撤销、编辑期间的持久续期、跨账号写入拒绝及受限评论 PoW 已有实库与浏览器证据。 | 公网部署、完整管理员角色、动态风险、强匿名及旧凭据切换。 |
| 内容、工作区与沟通 | FsusUI 源码双组已验证持久顺序、跨屏折叠、活动稿件移动和合并。已实测作者文章库、标题摘要、属性筛选、保存视图、私有媒体和明确选择的公开图片及撤回、万节点 Canvas、显式及视觉边原子转换。工单、站内信、WebSocket 重连、作者删除、登录回复通知、独立申诉复核和待审批量批准与驳回均有原生与实际浏览器结果。 | 富编辑器完整跨组状态恢复、保存视图全量迁移、Canvas 标题和块链接及完整无障碍、公开附件网关预算、管理员实时流、外部订阅提供方及其余评论状态与异常身份。 |
| 迁移与扩展 | 实库验证私有媒体备份及公开派生图片重建、三库方言隔离候选续跑和恢复、旧首次及第二次即时发布和第三次公开回滚的终态 Outbox 保全。macOS 离线插件、签名外观、单字体原始档、选定 `.fstheme` 结构核验和 Markdown/Word 导出已实测。Debian ARM64 已验证 seccomp 和 cgroup 限额及回收。 | 完整旧库转换、身份媒体权限对账和激活、备份密钥与生产交接、Linux 托管插件和在线运行时、v1 主题激活、通用字体及其余文档格式。 |
| 性能与稳定性 | 原生直连、Caddy TLS、冷缓存、隔离故障及完全清理均有证据。堆硬上限长测 900 秒、RSS 峰值 842,800 KiB，四条热读零数据库命令。 | 两次合格直连与代理容量矩阵、独立供给余量。最新 TLS 最高档本机样本的漏发率为 0.10683%。 |
| 发布包 | macOS 上由锁定引用生成运行包和完整 Git bundle，独立导入后核对摘要、Git 和真实媒体运行。Debian 13 ARM64 通过同一框架依赖发布包摘要校验、PostgreSQL 迁移及重启前后公开快照复核。 | 从最终验收提交生成并验证目标平台发布包。外部执行 Docker 验收，单列结果。完整代码量重新计算。 |

未通过的样本保留在 [性能诊断](../tests/Performance/)中。产品和议题边界以[执行状态](status.md)、[风险条款](issues/risk-trace.md)、[发布及身份条款](issues/risk-release-trace.md)和[剩余代码预算](product/code-budget-checkpoint.md)为准。

在工作树中运行 `python3 -B tools/verify-release.py RELEASE_DIRECTORY`，可逐项核对归档内文件、三项原始 FsusUI Wasm、发布坐标及完整 Git 历史。验证从空 Git 仓库导入 bundle，并返回候选和 FsusUI 提交、归档文件数及历史提交数。应用用例由独立原生和浏览器入口验证。
