# 发布验收仍需验证的边界

目前的 Git 历史包含可运行的 v2 和多次独立候选。每项证据只适用于对应提交、配置、工具链和输入。最终发布需要从同一冻结提交复验各域并证明完整性。

| 验收项 | 已验证的范围 | 发布前仍需完成 |
| --- | --- | --- |
| 公开发布与读取 | 实库和 Chrome 覆盖保存、CAS、发布、撤回、定时发布、权利快照和 outbox 恢复。已实测旧发布失效、租约交接、冷读限制、标准订阅源、相关文章与同代索引复用。 | v1 完整状态流、公开回滚、Rights V3 签名和透明度、热度与索引补丁。 |
| 身份与授权 | 双 HTTPS 主机覆盖独立管理员 Passkey、独立审计权限、Cookie 隔离和来源拒绝，站点账号经过 TOTP、单用恢复码、会话撤销和受限评论 PoW。 | 公网部署、完整管理员角色与敏感操作、动态风险与强匿名、持久刷新、恢复与旧凭据切换。 |
| 内容、工作区与沟通 | FsusUI 编辑器与多标签、账号草稿恢复、八类属性、Canvas 图和持久撤销重做、私有媒体续传、带 PoW 工单和私有 WebSocket 重连已具备实测。 | 工作区剩余交互和崩溃恢复、Canvas 锚点和规模、附件引用和票据、完整工单管理、订阅和审核。 |
| 迁移与扩展 | 实际离线 PostgreSQL 和媒体备份恢复，三方言旧库到不可启动候选库的续跑和恢复，签名扩展离线隔离以及签名配色、字体启用已有实测。作者可下载已保存的 Markdown 修订。 | 完整 v1 数据转换、身份媒体权限对账和激活、备份密钥与生产交接、插件运行时、v1 主题和字体管理、文档转换。 |
| 性能与稳定性 | 原生直连、Caddy TLS、冷缓存、失败恢复、运行时归因均有数据。 | 两次通过固定直连和代理容量门槛、完整长时资源与单机边界证据、独立供给者容量。 |
| 发布包 | macOS 上由锁定引用生成运行包和完整 Git bundle，独立导入后核对摘要、Git 和真实媒体运行。 | 从最终验收提交生成并验证目标平台发布包。外部执行 Docker 验收，单列结果。完整代码量重新计算。 |

未通过的样本保留在 [性能诊断](../tests/Performance/)中。产品和议题边界以[执行状态](status.md)、[风险条款](issues/risk-trace.md)、[发布及身份条款](issues/risk-release-trace.md)和[剩余代码预算](product/code-budget-checkpoint.md)为准。
