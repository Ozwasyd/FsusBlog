# 发布验收仍需验证的边界

目前的 Git 历史包含可运行的 v2 和多次独立候选。每项证据只适用于对应提交、配置、工具链和输入。最终发布需要从同一冻结提交复验各域并证明完整性。

| 验收项 | 已验证的范围 | 发布前仍需完成 |
| --- | --- | --- |
| 公开发布与读取 | 实库和 Chrome 覆盖保存、CAS、发布、撤回、定时发布、权利快照和 outbox 恢复。已实测管理员回滚到公开版、作者草稿或归档，以及从归档重新发布。租约交接、冷读限制、搜索变更页下载及标准订阅源已验证。物理备库升主验证旧实例拒绝、原发布读取与幂等重试。原生权利证明、浏览器验签、同事务签发、外部锚定的签名日志头及离线发布 Merkle 检查点均有验证。真实 HTTPS 停留统计及可选热门列表已验证，榜单热读零数据库调用。 | 非公开来源矩阵、归档预览、完整历史责任、公开成员证明、每日检查点与公证、FSPT 在线传输、原 Wasm 排名等价、生产集群编排与重新入组。 |
| 身份与授权 | 双 HTTPS 主机覆盖独立管理员 Passkey、独立审计权限、Cookie 隔离、来源拒绝、当前授权和私有近期成功登录。账号 TOTP、一次性恢复码、Recovery Key 重绑 Passkey、会话撤销、编辑期间的持久续期、跨账号写入拒绝及受限评论 PoW 已有实库与浏览器证据。普通账号自己的凭据清单及 WebAuthn 计数器回退拒绝另经验证。 | 公网部署、完整管理员角色、动态风险、强匿名及旧凭据切换。 |
| 内容、工作区与沟通 | FsusUI 源码双组已验证持久顺序、跨屏折叠、活动稿件移动和合并。已实测作者文章库、标题摘要、属性筛选、保存视图、私有媒体和明确选择的公开图片及撤回、万节点 Canvas、显式及视觉边原子转换。工单、站内信、WebSocket 重连、作者删除、登录回复通知、独立申诉复核和待审批量批准与驳回均有原生与实际浏览器结果。 | 富编辑器完整跨组状态恢复、保存视图全量迁移、Canvas 标题和块链接及完整无障碍、公开附件网关预算、管理员实时流、外部订阅提供方及其余评论状态与异常身份。 |
| 迁移与扩展 | 实库验证私有媒体备份及公开派生图片重建、三库方言隔离候选续跑和恢复、旧首次发布、再发布和公开回滚的终态 outbox 保全。已在独立可丢弃的副本真实启动首发记录并验证重启。macOS 离线插件、签名外观、单字体原始档、选定 `.fstheme` 配色和 Markdown/Word 导出已实测。真实 HTTPS 验证配色切换、回退及撤销。Debian ARM64 核验了默认关闭的离线签名插件宿主、沙箱限额、信任变化和调用者异常退出后的回收。 | 完整旧库转换、身份媒体权限对账和激活、备份密钥与生产交接、在线插件运行时、通用旧主题和字体及其余文档格式。 |
| 性能与稳定性 | 原生直连、Caddy TLS、冷缓存、隔离故障及完全清理均有证据。堆硬上限长测 900 秒、RSS 峰值 842,800 KiB，四条热读零数据库命令。两轮本机直连最高档达到数字门槛。新候选系统采样时直连与 TLS 各正确完成 660,000 次请求。C11 小规模 PostgreSQL 语料验证了 20 篇文章和 132 条评论的独立读回。 | 须在冻结条件下验证稳定供给。11,000 档无额外采样时分别漏发 1,052 和 968 次。正式两轮 Caddy TLS 最高档均超过漏发门槛。C11 的 10 万篇文章及 100 万条评论、独立百万篇文章档位仍需实测。 [容量矩阵](../tests/Performance/matrix-2026-11-15.md#堆硬上限及连接复用第二轮) · [供给诊断](../tests/Performance/supplier-2026-11-15.md) · [规模条件](issues/risk-instance-scale.md) |
| 发布包 | macOS 上由锁定引用生成运行包和完整 Git bundle，独立导入后核对摘要、Git 和真实媒体运行。Debian 13 ARM64 通过同一框架依赖发布包摘要校验、PostgreSQL 迁移及重启前后公开快照复核。 | 从最终验收提交生成并验证目标平台发布包。外部执行 Docker 验收，单列结果。完整代码量重新计算。 |

未通过的样本保留在 [性能诊断](../tests/Performance/)中。产品和议题边界以[执行状态](status.md)、[风险条款](issues/risk-trace.md)、[发布及身份条款](issues/risk-release-trace.md)和[剩余代码预算](product/code-budget-checkpoint.md)为准。

在工作树中运行 `python3 -B tools/verify-release.py RELEASE_DIRECTORY`，可逐项核对归档内文件、三项原始 FsusUI Wasm、发布坐标及完整 Git 历史。验证从空 Git 仓库导入 bundle，并返回候选和 FsusUI 提交、归档文件数及历史提交数。应用用例由独立原生和浏览器入口验证。
