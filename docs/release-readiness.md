# 发布验收仍需验证的边界

目前的 Git 历史包含可运行的 v2 和多次独立候选。每项证据只适用于对应提交、配置、工具链和输入。最终发布需要从同一冻结提交复验各域并证明完整性。

| 验收项 | 已验证的范围 | 发布前仍需完成 |
| --- | --- | --- |
| 公开发布与读取 | 实库和 Chrome 覆盖保存、CAS、发布、定时命令、撤回与 outbox 恢复。已实测旧发布失效、租约交接、冷读限制、标准订阅源与相关文章。 | v1 完整状态流、带不可变 Rights V3 的公开回滚与透明度、热度与索引补丁。 |
| 身份与授权 | 双 HTTPS 主机覆盖独立管理员 Passkey、Cookie 隔离和来源拒绝，站点账号经过 TOTP、单用恢复码、会话撤销和受限评论 PoW。 | 公网部署、完整管理员角色与敏感操作、动态风险/强匿名、持久刷新、恢复与旧凭据切换。 |
| 内容、工作区与沟通 | FsusUI 编辑器与多标签、账号草稿恢复、八类属性、Canvas 图、私有媒体、带 PoW 工单和私有通知已具备实测。 | 工作区剩余交互和崩溃恢复、Canvas 持久撤销重做、资产引用和分片、完整工单管理、订阅和审核。 |
| 迁移与扩展 | 实际离线 PostgreSQL 和媒体备份/恢复，三方言只读及影子转换，签名扩展的离线持久权限与隔离。作者可下载已保存的 Markdown 修订。 | 实际 v1 数据转换与断点 apply、身份媒体权限对账、恢复后激活、备份密钥与生产交接、插件运行时、文档转换、主题和字体。 |
| 性能与稳定性 | 原生直连、Caddy TLS、冷缓存、失败恢复、运行时归因均有数据。 | 两次通过固定直连和代理容量门槛、完整长时资源与单机边界证据、独立供给者容量。 |
| 发布包 | macOS 上由锁定引用生成运行包和完整 Git bundle，独立导入后核对摘要、Git 和真实媒体运行。 | 从最终验收提交生成并验证目标平台发布包。外部执行 Docker 验收，单列结果。完整代码量重新计算。 |

未通过的样本保留在 [性能诊断](../tests/Performance/)中。产品和议题边界以[执行状态](status.md)、[风险条款](issues/risk-trace.md)、[发布及身份条款](issues/risk-release-trace.md)和[剩余代码预算](product/code-budget-checkpoint.md)为准。
