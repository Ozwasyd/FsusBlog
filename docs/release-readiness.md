# 发布验收仍需验证的边界

目前的 Git 历史包含可运行的 v2 和多次独立候选。每项证据只适用于对应提交、配置、工具链和输入。最终发布需要从同一冻结提交复验各域并证明完整性。

| 验收项 | 已验证的范围 | 发布前仍需完成 |
| --- | --- | --- |
| 公开发布与读取 | 实库和 Chrome 覆盖保存、CAS、发布、撤回、定时发布、权利快照和 outbox 恢复。已实测管理员向公开版本回滚、旧发布失效、租约交接、冷读限制、标准订阅源、相关文章与同代索引复用。 | v1 完整状态流、回滚到草稿和归档、Rights V3 签名和透明度、热度与索引补丁。 |
| 身份与授权 | 双 HTTPS 主机覆盖独立管理员 Passkey、独立审计权限、Cookie 隔离、来源拒绝和当前授权展示。账号 TOTP、单用恢复码、Recovery Key 重绑 Passkey、会话撤销、编辑期间的持久续期、跨账号写入拒绝及受限评论 PoW 已过实库与浏览器验证。 | 公网部署、完整管理员角色、动态风险与强匿名及旧凭据切换。 |
| 内容、工作区与沟通 | FsusUI 单组标签及检查器恢复、作者文章库、组合属性筛选与个人保存视图、私有媒体续传与修订引用、万节点 Canvas 和显式文章链接事务、工单读写、状态与共享未读、管理员单账号通知、私有 WebSocket 重连、单项评论审批、评论作者删除、管理端站点 Markdown 发布与标签改名均已实测。 | 工作区多组布局与编辑器状态恢复、保存视图全量迁移、Canvas 标题和块链接及完整无障碍、公开附件、工单活动排序及管理员实时流、订阅投递、批量审核和申诉。 |
| 迁移与扩展 | 实际离线 PostgreSQL 和媒体备份恢复，三库方言旧库到不可启动候选库的续跑和恢复、支持的即时发布和公开回滚投影、首次定时发布证据、选定管理员与媒体封包均有实测。受限纯插件 Hook 可在 macOS 离线执行，签名 FsusUI 配色与字体可启用和回滚。已验证单字体 v1 原始归档。作者可下载当前及历史 Markdown 和 Word 修订。 | 完整 v1 数据转换、身份媒体权限对账和激活、备份密钥与生产交接、在线插件运行时、v1 主题、通用字体加载与其余文档转换。 |
| 性能与稳定性 | 原生直连、Caddy TLS、冷缓存、失败恢复、运行时归因均有数据。 | 两次通过固定直连和代理容量门槛、完整长时资源与单机边界证据、独立供给者容量。 |
| 发布包 | macOS 上由锁定引用生成运行包和完整 Git bundle，独立导入后核对摘要、Git 和真实媒体运行。Debian 13 ARM64 通过同一框架依赖发布包摘要校验、PostgreSQL 迁移及重启前后公开快照复核。 | 从最终验收提交生成并验证目标平台发布包。外部执行 Docker 验收，单列结果。完整代码量重新计算。 |

未通过的样本保留在 [性能诊断](../tests/Performance/)中。产品和议题边界以[执行状态](status.md)、[风险条款](issues/risk-trace.md)、[发布及身份条款](issues/risk-release-trace.md)和[剩余代码预算](product/code-budget-checkpoint.md)为准。
