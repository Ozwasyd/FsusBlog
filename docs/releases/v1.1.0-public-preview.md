# v1.1.0 Public Preview

FsusBlog v1.1.0 is a public-preview release. It is usable for development, evaluation, code review, and personal self-hosting experiments, but it is not stable production software and has no production SLA.

## Available Capabilities

- Single-process Kestrel application baseline.
- AEDS binary runtime API baseline.
- Public HotRead and Public AOT public reading paths.
- Vue frontend, public hydration, admin console, and authoring workflow baseline.
- PoW, MFA, Passkey, session, anti-crawler, moderation, audit, and security console baseline.
- Public-preview contribution, security reporting, dev onboarding, and documentation entry points.

## Experimental Or Unstable Capabilities

- Internal AEDS frame contracts.
- Undocumented internal APIs.
- Database schema.
- Admin API routes and workflows.
- Deployment configuration.
- Performance profiles outside documented benchmark mode and environment.
- Third-party client compatibility.

## Breaking-Change Policy

During v1.1.x, undocumented internal APIs and AEDS frames may change without compatibility guarantees. Stable public extension points will be documented explicitly in later versions.

## Deployment Notes

The internal project baseline is Kestrel-only and single-process. Reverse proxies and CDNs are optional deployment layers and must not be mixed into internal performance claims unless the benchmark explicitly says so.

Start local development with:

```bash
./tools/dev/start.sh --seed-demo
```

## No Production SLA

This release does not provide production support, uptime guarantees, response time commitments, or stable third-party client compatibility.
