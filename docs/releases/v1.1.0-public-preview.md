## Deployment Notes

The internal project baseline is Kestrel-only and single-process. Reverse proxies and CDNs are optional deployment layers and must not be mixed into internal performance claims unless the benchmark explicitly says so.

Start local development with:

```bash
./tools/dev/start.sh --fixture-profile demo-public
```

Configuration authority is `src/backend/appsettings.json` plus the environment overlay: the checked-in `src/backend/appsettings.Production.json` at runtime or the minimal `src/backend/appsettings.Development.example.json` for local development. `.env.example` remains the local-development template; production operators copy `.env.production.example` to a private `.env.production` and replace every `CHANGE_ME` value.
