单进程公开快照受 PostgreSQL 独占租约保护。撤回、删除或发布进入提交时使当前快照不可用，提交后根据已提交修订刷新。AEDS、HTML 和分片搜索索引来自同一公开代次。租约失效后服务停止提供快照和接收事务。备用进程在同一 PostgreSQL 主库上等待旧事务退出并重建快照。[单机数据库租约与交接](publication-lease.md)
